# rainy-konbini

Third-party full-screen effect used by the site entry **雨夜便利店**.

- Source: <https://github.com/Ri1035/rainy-konbini>
- File: `rainy-konbini.html` — the upstream self-contained single-file build
- Integration: loaded in a full-screen iframe from
  Settings → 特效设置 → 雨夜便利店 (`RainyKonbiniOverlay.svelte`)
