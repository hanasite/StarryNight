# rainy-konbini

Third-party full-screen effect used by the site entry **雨夜便利店**.

- Source: <https://github.com/Ri1035/rainy-konbini>
- File: `rainy-konbini.html` — rebuilt from the upstream source after local changes:
  - 7-Eleven-style storefront signage (main sign, vertical lightbox, door sign,
    nobori flags, sidewalk A-board)
  - street-level initial camera aimed at the store entrance from across the road
- Integration: site mode with a full-screen iframe background, a bottom round
  menu, and page content shown in overlay mode over the scene
  (`RainyKonbiniMode.svelte`, `src/styles/rainy-konbini.css`)

for usage terms before redistributing this file.
